浅色主题 · Tab 选中态方案

同一个“变量筛选”上下文下对比 6 种方向。当前浅蓝色填充偏淡，也容易被 #DDF4FF 的整页浅蓝淹没；下面几种方案拉开了选中层级，您选一个后我再落到应用里。

当前待替换 浅蓝填充 #C9E8FF · #0550AE
当前版本
选中与未选中都落在浅蓝区间，层级不够明显。
01

墨蓝实底

用深墨蓝做选中底，和白底形成明确反差；保留蓝色系，但不再是“淡蓝色块”。

推荐

变量筛选

特点对比度最高，一眼能看出当前筛选；适合作为主交互色，不会像亮蓝实底那样抢眼。

02

石墨药丸

用中性石墨黑做选中底，蓝色只保留在文字和计数上，整体更克制。

变量筛选

特点最中性、不挑页面；适合希望界面“少一点品牌蓝”的方向。

03

下划线

去掉填充，选中项只用深蓝文字和 2px 下划线标记，接近 GitHub 的页签语言。

变量筛选

特点最轻、最透气；适合内容区较密集的页面，但点击区域不如药丸明显。

04

靛蓝柔雾

把当前蓝色往靛蓝方向偏移，选中底更柔，和整页的蓝灰调拉开一点色相。

变量筛选

特点更年轻、更柔和；适合希望保留浅色底但不想再用同一块浅蓝的方向。

05

白底描边

选中项变回白底，用蓝色边框和外圈光晕标记，整体像一组精致的分段控件。

变量筛选

特点最清爽、边界最清楚；适合表单和筛选器较多的页面。

06

左侧色条

选中项保留白底和细边框，用左侧 3px 蓝色竖条做导航式强调。

变量筛选

特点和侧栏导航语言一致；适合想让“筛选”更像导航层级的方向。
