日志行拼接功能号与服务标识

格式 POST /reqxml/{action}/{值}

共同规则：只对 /reqxml（含 /ant/reqxml 这类带前缀的路径）生效； action 或 serviceId 缺失时按上面的顺序省略后面的段，两个都没有就保持现状文案； 重复键取最后一个值，与请求发送逻辑一致；详情面板里的「源码」视图仍然显示原始请求行，不受影响。
