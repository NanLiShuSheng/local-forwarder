Request · Login Cache Reminder

请求模块 · 登录缓存提醒原型

提醒只针对登录请求：Action=100 / 104 / 105 成功后，应答键值会自动写入当前代理的「登录缓存」，普通请求不受影响。下面比较 3 种提示位置。

提示文案 登录应答会自动缓存 信息提示，不使用警告色；不提供关闭按钮，避免关键行为被永久隐藏。

页面顶部提示条

推荐

放在请求面板最上方，打开页面即可看到。信息层级清楚，最符合“主动告知用户”的目标。

优点 可见性最高，和输入/发送没有耦合。 代价 占用约 60px 首屏空间。
