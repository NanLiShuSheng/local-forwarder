# 界面细节优化设计

**日期：** 2026-09-18  
**状态：** 待实现

## 目标

在不改变请求、JSON 解析、配置保存和日志筛选行为的前提下，统一几个容易产生拥挤或错位的界面细节：请求响应耗时、JSON 工具栏、变量/缓存输入区，以及选择框箭头。

## 已确认范围

### 1. 请求响应耗时与复制按钮分层

保留请求耗时，并固定保留 `ms` 单位：

- 未发送请求时显示 `耗时 — ms`。
- 请求完成后显示 `耗时 {durationMs} ms`。
- 耗时作为独立的弱强调信息块，放在响应卡标题右侧。
- “复制应答数据”和“已复制”状态组成独立操作组，与耗时信息之间保留明显间距。
- 响应标题区域允许换行；窄窗口下耗时和操作组可以自然换行，不能挤压复制按钮或响应正文。

### 2. JSON 可视化移除“复制当前路径”按钮

JSON 工具栏保留搜索、全部展开和全部收起，移除“复制当前路径”按钮及其专用回调。`selectedPath` 仍用于节点选中态和图片导出，不改变树形/表格展开、选择和导出行为。

同步更新底部提示，删除“点击字段可复制路径”这类不再成立的文案，保留节点展开、选中和长文本展示说明。

### 3. 本地变量与登录缓存输入区统一

两页使用同样的内容顺序和间距：

1. 说明文字；
2. 文本输入框；
3. 保存错误提示（如有）。

登录缓存的“当前代理已缓存 N 项……”说明移到文本框上方，与本地变量说明共用一个辅助文字样式。两页仍保留各自的文本框高度和数据格式，不改变自动保存、解析或缓存数量逻辑。

### 4. 选择框箭头内缩

为当前应用中可见的选择框建立共享视觉规则，覆盖：

- 请求模块的协议筛选；
- 字符串工具的处理操作；
- 日志页的日志类型和日志级别筛选。

选择框使用统一的内缩箭头，箭头距右边约 10–12px；右侧增加足够的文本内边距，避免选项文字与箭头重叠。保留原生键盘操作、选项弹层和焦点状态，深色/浅色主题均使用当前主题文字颜色绘制箭头。

## 方案与取舍

采用轻量的共享样式方案：只为选择框增加一个共享 class 和主题感知的 CSS 箭头，为请求耗时和变量/缓存说明增加语义 class；不引入新的通用 React 组件。

这样可以覆盖现有的三个选择框场景，同时控制 JSX 结构改动范围。引入独立选择框组件会增加抽象和测试成本；只修请求页则会留下字符串工具和日志页的不一致，因此不采用。

## 验收标准

- 请求页响应标题中，耗时与复制按钮视觉上分组且不相贴；实际响应仍显示 `ms`。
- JSON 可视化工具栏没有“复制当前路径”按钮或过时提示，其他展开、收起、导出和选中行为仍在。
- 本地变量和登录缓存的辅助文字都位于输入框上方，文本框风格和垂直间距一致。
- 请求、字符串、日志选择框的箭头都明显内缩，且深色/浅色主题下可见；键盘 Tab 和原生选择行为不受影响。
- 现有共享值、登录缓存、请求发送、JSON 解析和日志筛选测试不回归。
- 目标验证命令：
  - `npx tsx --test test/renderer/request-panel.test.ts test/renderer/json-preview.test.ts test/renderer/chinese-ui.test.ts test/renderer/log-panel.test.ts test/renderer/string-tool.test.ts`
  - `npm test`

## 非目标

- 不修改请求耗时的计算方式或数据类型。
- 不删除 JSON 节点选中状态，不改变图片导出内容的数据来源。
- 不合并本地变量和登录缓存的数据存储，也不改变保存时机。
- 不改变选择框的选项内容、排序或业务逻辑。
