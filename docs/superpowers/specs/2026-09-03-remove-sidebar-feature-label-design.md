# 侧栏移除“功能”标题设计规格

## 目标

移除左侧功能 tab 上方可见的“功能”标题，同时保留 tab 的顺序、选中态、点击行为和无障碍导航名称不变。

## 方案

在 `src/renderer/App.tsx` 中移除 `.sidebar-nav-label` 的可见文本节点；在 `src/renderer/styles.css` 中用无内容的布局占位保留原标题区域高度，避免代理列表与 tab 区域发生不必要的跳动。`nav` 的 `aria-label="功能导航"` 保留，因为它是屏幕阅读器语义，不是用户界面上的可见标题。

## 范围与交互

- 不修改 `pages` 数据、tab 文案、路由状态或页面内容。
- 不修改 tab 选中高亮、悬停、键盘焦点和主题样式。
- 不新增 IPC、持久化字段或运行时逻辑。

## 验证

- 增加 renderer contract，确认可见 `.sidebar-nav-label` 与“功能”标题节点不存在。
- 保留并运行现有导航与侧栏 tab 样式测试，确认 tab 仍存在且行为未变。
- 使用项目现有类型检查/测试命令验证构建无回归。
