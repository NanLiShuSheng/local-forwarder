# GRID0 管道分隔数组可视化设计

## 目标

在 JSON 可视化的树形视图中识别由字符串数组组成、且每项使用 `|` 分隔的特殊数组（例如 `GRID0`），将其展开为按字段顺序对齐的表格，便于核对数组索引和值。

## 行为

- 仅识别非空数组，并要求数组每一项都是包含 `|` 的字符串；普通数组保持现有树形展示。
- 第一项作为字段名行，其余项作为数据行。
- 每项使用 `split("|")`，保留尾部分隔符产生的空字段。
- 以所有拆分行的最大长度作为列数；较短行在末尾补空字符串，任何空值都不前移。
- 表格首行显示索引 `0、1、2...`，第二行显示字段名，后续显示“数据 1、数据 2...”及对应值。
- 特殊数组表格只在树形节点展开时显示；原始 JSON 和现有表格视图保持原行为。

## 交互与样式

- 表格外层限制在预览内容宽度内，字段较多时仅表格区域出现横向滚动。
- 左侧索引/行名列使用 `position: sticky; left: 0` 固定，滚动后仍可对应数据。
- 空字段保留空白单元格，并使用轻微背景区分，不显示替代字符。
- 表格支持窄屏，不能造成页面整体横向溢出。

## 错误与边界

- 空数组、非字符串数组、混合数组或不含 `|` 的字符串数组不进入特殊渲染。
- 只有字段名没有数据行时仍显示字段索引和字段名，不伪造数据。
- 数据行比字段名更长时扩展列数，字段名缺失列保持空白。
