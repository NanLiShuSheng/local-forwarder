# 加密栏目设计说明

## 目标

在本地转发工具中增加“加密”栏目，允许用户选择加密前目录和加密后目录，并调用项目提供的 `h5encode-mac-amd64` 递归处理 H5 资源。功能只在本机执行，不通过代理服务发送请求。

## 行为规则

- 递归扫描源目录，保留相对目录结构。
- 忽略隐藏文件、隐藏目录、`node_modules`、`dist` 和 `.map` 文件。
- 普通文件每次全量处理，输出文件名为原文件名追加 `.d`。
- 每个文件先复制到独立临时目录，再调用编码器，等待同名 `.d` 生成后复制到输出目录。
- 输出目录自动创建；成功后写入 `.encrypt-cache.json` 记录本次文件 SHA-256 状态，但不启用增量跳过。
- 源目录必须存在且为目录；编码器必须存在且可执行。
- 输出目录不能与源目录相同，也不能位于源目录内部，避免重复扫描和覆盖源文件。
- 任一文件失败时终止任务、清理当前临时目录，并将错误反馈给页面。

## 架构与数据流

渲染进程只负责页面状态和用户操作，通过 preload 暴露的白名单 API 请求主进程：

1. 用户点击“选择目录”，主进程使用 Electron `dialog.showOpenDialog` 返回目录路径。
2. 用户点击“开始加密”，主进程解析应用资源中的编码器路径，校验目录关系并调用核心加密模块。
3. 核心模块扫描、临时复制、调用编码器、复制输出并返回处理文件清单和日志。
4. 渲染页展示运行中、成功数量或错误信息；运行期间禁用目录选择和开始按钮。

编码器放入 `resources/protocol/encode`，开发环境从项目资源目录读取，打包后从 `process.resourcesPath/protocol/encode` 读取。现有 `extraResources` 会将该目录带入 DMG。

## UI

左侧导航新增“加密”。页面沿用现有面板风格，包含：

- 加密前文件夹目录：只读路径输入框和“选择目录”按钮。
- 加密后文件夹目录：只读路径输入框和“选择目录”按钮。
- “开始加密”按钮。
- 当前状态、处理数量、最近处理日志。

## 错误处理

目录选择取消不显示错误；目录无效、目录关系不安全、编码器不可执行、编码器未生成 `.d` 文件或文件复制失败时，统一通过 IPC 返回 `{ ok: false, error }`，页面显示可读错误。

## 测试范围

- 核心模块覆盖递归扫描、排除规则、相对路径、`.d` 输出、编码器调用、临时目录清理、全量重复执行和路径安全校验。
- IPC 合同覆盖新 channel、preload API 和主进程资源路径。
- 渲染测试覆盖栏目、两个目录选择项、执行按钮、运行状态和错误/结果文案。
- 完整 `npm test` 和 DMG 校验必须通过。
