# 左右内容独立滚动设计规格

## 背景

当前应用采用左侧导航栏、右侧内容区的横向布局，但外层只设置了最小高度，没有把两列限制在窗口视口内。右侧内容变长后，浏览器使用页面级滚动，导致左侧导航随右侧一起向上移动。

目标是让右侧内容滚动时左侧保持当前位置；当左侧自身内容超出窗口时，左侧可以使用自己的滚动容器独立滚动。

## 已确认方案

采用独立滚动容器方案：

- `.app-shell` 固定为窗口视口高度并隐藏页面级溢出，避免 `body` 成为左右两栏的共同滚动容器。
- `.sidebar` 使用视口高度、允许垂直滚动；左侧代理实例列表已有的内部滚动保持不变。
- `.content` 使用视口高度并允许垂直滚动，右侧长页面只在右侧内容区内滚动。
- 两个滚动区使用 `min-height: 0`，确保它们在 flex 布局中可以收缩到视口高度，而不是把外层撑高。
- 右侧滚动区设置滚动边界隔离，避免到达滚动边界时把滚动继续传递给外层。

## 适用范围

仅修改 renderer 布局 CSS 和对应的 CSS 契约测试，不改变 React 页面结构、页面路由、代理配置、IPC 或运行状态行为。

目标选择器：

```css
.app-shell
.sidebar
.content
```

保留现有 `.proxy-instance-sidebar-list` 的 `max-height` 和 `overflow-y: auto`，使代理卡片列表继续在左侧自己的列表区域滚动。

## 交互验收标准

- 右侧内容超过窗口高度时，滚动右侧内容，左侧导航和代理实例区域位置不变化。
- 左侧导航或其他左侧内容超过窗口高度时，左侧可以单独垂直滚动，不改变右侧滚动位置。
- 代理实例超过列表展示高度时，实例列表仍可独立滚动，不影响左侧导航和右侧内容。
- 页面不出现由 `.app-shell` 或 `body` 产生的第三个共同垂直滚动条。
- 横向布局、响应式断点、深色/浅色主题和现有嵌套内容滚动区域保持不变。

## 测试计划

- 增加 renderer CSS 契约测试，确认应用根布局锁定视口并隐藏外层溢出。
- 确认左侧和右侧均声明视口高度、`min-height: 0` 与垂直滚动行为。
- 确认右侧设置滚动边界隔离，且代理实例列表原有独立滚动规则仍存在。
- 运行新增的 renderer 专项测试、全量测试、生产构建和 `git diff --check`。

## 非目标

- 不通过 JavaScript 监听或重写滚轮事件。
- 不改变左侧代理实例数量限制、导航顺序或页面内容。
- 不调整滚动条样式、间距或视觉主题。
