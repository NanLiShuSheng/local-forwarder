# 概览运行态与代理列表布局设计

## 目标

调整概览页和左侧代理列表的运行态视觉，使操作状态更明确：

- 概览中的“停止代理”使用左侧“一键关闭”的红色危险按钮样式。
- 代理运行时，概览中的项目目录、监听主机、监听端口和超时时间不可编辑，并呈现禁用态。
- 左侧代理卡片中，运行状态紧跟代理名称显示。
- 左侧代理卡片中的端口号固定在最右侧并右对齐。

## 方案

沿用现有 React 组件和 CSS 类，不增加数据接口或新的运行状态。`ProxyInstancePanel` 根据 `status.state === "running"` 为概览配置输入和“选择项目目录”按钮设置禁用属性；启停过程仍使用现有 `busy` 状态。停止按钮复用侧栏一键关闭的 `.proxy-instance-sidebar-action.stop` 视觉语义，并在概览中保留按钮的交互行为。

`ProxyInstanceSidebar` 只调整卡片标题行的布局顺序和 CSS：状态节点位于名称之后，端口 `<code>` 通过 `margin-left: auto` 占据右侧空间；名称保持可截断，状态和端口不被压缩。

## 成功标准

- 运行中点击概览配置字段无法输入或触发保存。
- 停止代理后配置字段恢复可编辑。
- 概览“停止代理”与侧栏“一键关闭”具有相同红色边框、文字和半透明背景。
- 每个左侧代理卡片的状态都显示在名称右侧，端口号视觉上靠右对齐。
- 现有渲染测试和构建继续通过。
