# 浅色主题「清透薄荷」视觉重设计规格

## 背景

当前浅色主题以冷灰白 `#F4F7FB` 为主，应用画布、侧栏、面板和输入区域的明度差异较小，导致用户感受到的“白版”偏灰、层级不够清透。

本次确定采用 A「清透薄荷」方向，并允许同步微调边框、阴影和选中态。目标是在不改变页面结构和交互行为的前提下，让浅色主题更接近白色，同时保留现有绿色运行状态语义。

## 目标与边界

### 目标

- 主内容画布接近纯白，降低冷灰感。
- 侧栏使用极浅薄荷色，与主画布形成轻微但清楚的区域分隔。
- 卡片和输入框回到纯白，通过边框和极轻阴影建立层级。
- 运行中、主按钮、导航选中态统一使用清透的绿色强调色。
- 选中态、悬停态、聚焦态拥有明确反馈，但不产生大面积彩色填充。
- 深色主题、页面布局、组件尺寸、文案和业务逻辑保持不变。

### 不纳入范围

- 不重排侧栏、概览、日志、规则等现有页面结构。
- 不新增主题切换模式或新的设计系统依赖。
- 不调整功能流程、IPC、配置模型或运行状态逻辑。
- 不把警告、错误、信息状态改造成绿色；这些语义仍使用各自的颜色。

## 视觉方案

浅色主题采用五层空间关系：

```text
应用画布 #FCFEFD
  ├─ 侧栏层       #F2FAF7
  ├─ 次级背景     #F7FCFA
  ├─ 卡片/输入框  #FFFFFF
  └─ 选中层       #E4F5EF
```

### 核心色值

| 语义 | 色值 | 使用位置 |
| --- | --- | --- |
| 主画布 | `#FCFEFD` | 内容区、应用背景 |
| 侧栏背景 | `#F2FAF7` | 左侧实例与导航区域 |
| 次级背景 | `#F7FCFA` | 指标块、代码块、轻量分组 |
| 卡片白 | `#FFFFFF` | 面板、卡片、输入框 |
| 选中背景 | `#E4F5EF` | 当前实例、当前导航、选中控件 |
| 默认边框 | `#D7E9E3` | 面板、卡片、分隔线 |
| 强边框 | `#C8E1D9` | 按钮、输入框、地址标签 |
| 悬停边框 | `#55A892` | 可交互控件悬停/选中外框 |
| 主强调色 | `#247C67` | 主按钮、运行状态、激活导航 |
| 状态文字 | `#217660` | 成功/运行中的文字 |
| 主要文字 | `#17332F` | 标题、正文主信息 |
| 次要文字 | `#6A837C` | 描述、辅助信息、时间 |

### 层级与阴影

- 面板和卡片优先使用 `1px` 低饱和青灰边框；不依赖深色阴影制造边界。
- 普通卡片使用极轻阴影，目标视觉效果是“浮起一点”，不是灰色雾面。
- 菜单、强浮层可以使用更明显的阴影，但阴影色带绿色/青灰倾向，透明度保持低。
- 主内容区域不再使用明显的冷灰渐变；如保留背景渐变，只允许使用白色到极浅薄荷的低对比变化。

## 组件状态规则

### 代理实例与导航

- 未选中实例：纯白卡片、默认边框。
- 当前实例：背景 `#E4F5EF`，边框使用 `#55A892`，文字保持深绿，不使用纯绿色大面积填充。
- 当前导航：左侧强调线使用 `#247C67`，背景使用 `#E4F5EF`，图标与文字使用深绿。
- 悬停：背景使用更浅的薄荷色，边框或左侧线出现轻微强化。

### 运行状态与操作

- 运行中圆点使用 `#2C9B7A`，外圈使用极浅的 `#E2F5EE`。
- 运行中标签使用深绿色文字 + `#DFF3EC` 背景。
- 主操作按钮使用 `#247C67`，文字为白色；悬停时只加深绿色，不改变尺寸。
- 次要按钮保持白底，以 `#C8E1D9` 边框和深绿色文字表达可操作性。

### 面板、指标和日志

- 面板使用纯白背景和 `#D7E9E3` 边框。
- 指标块使用 `#F7FCFA`，不要使用当前偏灰的蓝灰背景。
- 日志分隔线使用 `#E4EFEB`；成功状态和 HTTP 200 可使用主强调绿色，普通时间和协议使用次要文字色。
- 代码、地址、输入区域保持高可读性：白底或极浅薄荷底，等宽文字使用深青灰。

### 聚焦、禁用、错误

- 聚焦环沿用绿色语义，使用主强调色的低透明度外圈，不改变控件底色。
- 禁用状态降低文字和边框对比度，但保留白底，避免变成灰块。
- 警告、错误、信息颜色继续沿用现有语义，仅在必要时调整其浅色背景与新画布的对比度。

## 实现约束

- 只修改浅色主题变量及其直接依赖的通用视觉规则；深色主题变量不得被覆盖。
- 优先通过现有 CSS custom properties 完成，不为单个页面复制一套颜色常量。
- 不改变现有 React 组件的 DOM 结构，除非现有选择器无法表达状态层级。
- 保持现有 `system / light / dark` 主题解析和本地持久化行为。
- 原型中展示的布局仅用于验证视觉层级，最终实现以当前页面真实组件为准。

## 验证标准

- 浅色主题主内容区域视觉上接近白色，不再呈现明显冷灰底。
- 侧栏、卡片、指标块、选中态可在不放大界面的情况下被区分。
- 运行中、主按钮、当前导航仍然能快速识别，且绿色不会覆盖过多面积。
- 深色主题截图/测试结果不发生变化。
- 现有主题、导航和中文 UI 测试通过；构建成功。
