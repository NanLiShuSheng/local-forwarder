# 左侧代理列表最多显示三个设计

## 目标

调整左侧代理实例列表的可视区域：最多同时显示 3 个代理实例；当代理实例超过 3 个时，继续保留全部实例，但仅在代理列表区域内纵向滚动查看。左侧功能导航和其他侧栏内容的位置不随代理数量变化。

## 方案

沿用现有 `ProxyInstanceSidebar` 的渲染和交互，只调整 `.proxy-instance-sidebar-list` 的布局高度与滚动约束：

1. 列表可视高度按 3 张现有代理卡片、卡片间距和列表内边距计算。
2. 列表继续渲染所有 `instances`，第 4 个及之后的实例通过 `overflow-y: auto` 查看。
3. 滚动容器保持当前滚动条样式；滚轮、触控板和滚动条只作用于代理列表。
4. 卡片选中、切换、双击启停、删除、一键开启/关闭和新增逻辑不改变。
5. 窄屏下保持最多同时显示 3 个实例，仅允许卡片随侧栏宽度收缩，不让列表扩展覆盖功能导航。

采用严格 3 张卡片高度的方案，不额外增加“还有更多”提示，以保持现有侧栏视觉简洁并将改动限制在必要范围内。

## 边界与错误处理

- 0–3 个代理实例时，列表不需要滚动，容器仍保持统一的最大可视高度。
- 超过 3 个实例时，只有代理列表出现纵向滚动，不影响页面主体和功能导航。
- 不新增数据字段，不改变代理实例持久化格式和运行时行为。

## 测试

- 更新渲染样式契约，验证代理列表存在固定的 3 卡片可视高度约束。
- 验证代理列表开启纵向滚动，且没有改变现有卡片渲染和操作标记。
- 运行现有 renderer 测试与完整测试命令，确认代理管理和其他页面无回归。
