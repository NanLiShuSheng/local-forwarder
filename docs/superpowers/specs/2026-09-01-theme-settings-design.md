# 主题设置设计规格

## 目标

为本地转发工具增加全局皮肤设置，支持浅色、深色和跟随系统三种模式。默认使用跟随系统，并让左侧代理实例栏与主内容区保持同一套主题，不出现“浅色内容区 + 深色侧栏”的混合状态。

## 已确认的界面方案

- 左侧“功能”导航新增“外观”页面。
- 外观页面使用三张主题卡片展示“跟随系统”“浅色”“深色”，卡片包含简化的界面预览。
- 当前选中项使用边框、勾选标记和“默认”标签表达；默认选中“跟随系统”。
- 点击主题卡片后立即生效，不增加保存/取消按钮。
- 页面显示当前主题和“即时生效”说明，并解释跟随系统会随 macOS 外观变化。
- 浅色模式下侧栏、代理实例卡片、导航、内容区、表单、面板、日志和状态颜色全部切换为浅色语义；深色模式保留现有深色视觉并统一使用主题变量。
- 跟随系统模式下，整套界面随 `prefers-color-scheme` 在浅色和深色之间切换。

原型参考：`docs/prototypes/` 中的主题预览方向；头脑风暴原型暂存于项目 `.superpowers/brainstorm/`，不纳入应用资源。

## 主题状态与持久化

主题设置是应用级偏好，不随代理实例切换。内部模式值固定为：

```text
system | light | dark
```

renderer 在启动时从 `localStorage` 读取主题模式，键名为 `local-forwarder.theme-mode`。缺失、无法读取或值不在上述枚举内时按 `system` 处理。选择新模式后立即写回；存储失败不阻塞界面更新，当前会话仍使用用户刚选择的模式。

实际渲染主题由两部分决定：显式选择 `light`/`dark` 时直接使用该值；选择 `system` 时读取 `window.matchMedia("(prefers-color-scheme: dark)")`。系统模式需要监听媒体查询变化，以便应用打开期间系统外观切换时同步更新。应用根节点使用 `data-theme="light"` 或 `data-theme="dark"`，同时设置对应的 CSS `color-scheme`。

## 组件与数据流

新增一个只负责主题偏好的 renderer 组件或 hook，职责包括：读取和校验模式、解析当前主题、监听系统外观、持久化选择并向页面提供切换方法。`App` 持有主题状态并将其应用到 `.app-shell` 或 renderer 根节点；`ConfigPages` 继续负责现有业务配置页面，不引入主题业务数据。

页面导航新增 `appearance` page。`App` 在该 page 渲染外观设置页面，并传入当前模式、解析后的当前主题和切换回调。主题切换只影响 renderer 的展示状态，不调用代理配置保存接口，不停止或重启运行中的代理实例。

## 样式策略

将 renderer 的共享颜色整理为语义化 CSS 自定义属性，至少覆盖：

- 应用背景、侧栏背景和侧栏边框；
- 主文字、次文字、禁用文字；
- 面板、输入框、代码块和列表项背景；
- 普通边框、悬停边框、焦点环和选中背景；
- 成功、警告、错误状态及其弱背景。

保留现有深色主题的视觉作为深色默认值，在 `[data-theme="light"]` 下提供对应的浅色值。高对比/焦点状态不能仅依赖颜色，继续保留边框或轮廓变化。输入、`select`、滚动条和状态徽标也必须使用当前主题的配色，避免系统控件仍显示深色方案。

原型中“减少动效”和“紧凑布局”仅作为未来扩展示意，本次不增加对应设置或行为。

## 错误与边界行为

- 读取到未知主题值：静默回退到跟随系统，并在下一次选择时覆盖旧值。
- `localStorage` 不可用：继续使用当前内存状态，默认按跟随系统，不显示阻断错误。
- `matchMedia` 不可用：系统模式回退到深色主题，显式浅色/深色不受影响；正常 Electron Chromium 环境必须走媒体查询。
- 系统外观变化只影响 `system` 模式；显式浅色或深色模式不被系统变化覆盖。
- 主题切换不修改业务配置、不影响 IPC、不改变代理运行状态和日志数据。

## 成功标准

- 首次打开应用时默认显示跟随系统，且当前系统为浅色/深色时整套界面对应显示。
- 外观页能明确看到三种模式和当前选中项；点击任一项后无需保存即可更新全局界面。
- 选择的模式在 renderer 刷新或应用重新打开后保持。
- 浅色模式下左侧栏与主内容区均为浅色；深色模式下均为深色；跟随系统切换时两者同步改变。
- 现有概览、请求、字符串、本地变量、登录缓存、加密和日志页面在两套主题下仍可读，输入焦点、按钮禁用、成功/警告/错误状态保持可辨识。
- 主题功能不新增代理 IPC，不改变现有代理配置和运行行为。

## 测试范围

- 主题模式读取、非法值回退、默认 system、显式主题解析和系统媒体查询变化。
- 点击三张主题卡片会更新当前模式并写入存储；存储异常不会阻止 UI 更新。
- `App` 导航包含“外观”页面，外观页展示三种模式和当前状态。
- CSS 主题选择器覆盖侧栏、内容背景、面板、输入、导航选中态、状态色和 `color-scheme`。
- 现有 renderer 测试、全量构建和测试继续通过。

## 明确不纳入本次范围

- 代理实例级主题设置。
- 云端同步、系统菜单或全局 macOS 外观设置修改。
- 减少动效、紧凑布局、字体大小、强调色和高对比度主题。
- 重新设计现有业务页面的布局和信息架构。
