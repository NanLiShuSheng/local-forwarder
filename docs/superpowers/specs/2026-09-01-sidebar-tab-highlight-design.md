# 侧栏 Tab 选中高亮设计规格

## 背景

当前左侧“功能”导航的选中态主要依赖底色变化。需要增强当前 tab 的位置识别，同时保持主题切换后的视觉一致性，并避免高亮效果抢过主内容。

## 已确认方案

采用 A 方案：柔和选中底色 + 左侧 3px 主题强调条。

- 选中 tab 保留语义化的选中背景色。
- 选中 tab 左侧增加 3px 垂直强调条，作为稳定的位置锚点。
- 选中文字使用主题中的高亮文字色；未选中项保持次级文字色。
- 不增加缩放、强阴影或额外动效，避免导航跳动和视觉噪声。
- 深色主题使用浅绿色强调条，浅色主题使用深绿色强调条。
- `:focus-visible` 继续使用独立的焦点环，焦点环与选中强调条同时存在时仍可辨认。
- 所有功能 tab 统一使用该选中态，包括“外观”。

## 适用范围

仅修改 renderer 侧栏导航的视觉样式和相关 CSS 契约测试，不改变页面路由、主题状态、代理配置、IPC 或运行状态行为。

目标选择器：

```css
.sidebar-nav button.active
```

实现应复用现有主题变量：

- `--surface-selected-background`
- `--text-bright`
- `--border-selected` 或等价的主题强调色
- `--focus-ring`

强调条应通过边框或等价的非布局位移方式实现，不能导致 tab 宽度或相邻内容发生跳动。

## 验收标准

- 深色主题下，选中 tab 同时有选中底色、左侧强调条和高亮文字。
- 浅色主题下，选中 tab 同时有浅色选中底色、左侧强调条和高亮文字。
- 未选中 tab 不显示左侧强调条；悬停态仍可与选中态区分。
- 键盘聚焦时焦点环清晰，不能被选中底色或强调条吞没。
- 点击任一 tab 只改变当前页面和视觉选中态，不调用主题/代理配置保存接口，不改变代理运行状态。
- 现有深色/浅色主题测试、renderer 测试、构建和全量测试继续通过。

## 测试计划

- 增加或更新 renderer CSS 契约测试，确认 `.sidebar-nav button.active` 使用主题选中背景、文字色和左侧强调条。
- 确认深色与浅色主题的强调条 token 存在且可辨识。
- 运行侧栏/中文界面专项测试、主题测试、全量测试和生产构建。
- 运行 `git diff --check`。
