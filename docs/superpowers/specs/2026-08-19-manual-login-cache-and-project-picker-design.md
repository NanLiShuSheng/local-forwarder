# 手动登录缓存与项目目录选择设计规格

## 目标

为桌面端增加两项配置能力：用户可以直接粘贴旧版 `_local` 登录缓存并保存；用户可以通过 macOS 系统目录选择框设置 H5 项目目录。

## 交互设计

### 登录缓存

- “变量”页面增加多行输入框和“保存登录缓存”按钮。
- 输入内容按多行 `键 = 值` 解析，忽略空行；只按第一个 `=` 分割，因此值中可以继续包含 `=`。
- 键和首尾空白去除，值保留内部空格；重复键以后出现的值为准。
- 粘贴内容与已有 `localValues` 合并，不删除原有未出现在粘贴内容中的变量。
- 保存失败时显示中文错误；服务运行中时沿用现有配置保存限制，提示先停止服务。
- 保存后清空输入框并刷新缓存数量；敏感值仍只显示掩码。

### 项目目录

- “设置”页面保留当前路径展示，增加“选择项目目录”按钮。
- Renderer 通过受信任的 preload IPC 请求主进程打开 `openDirectory` 系统选择框。
- 用户取消选择时不修改配置；选择成功后将绝对路径写入 `projectPath` 并保存内部配置。
- 目录选择和配置保存失败时显示错误，不直接访问文件系统。

## 数据流与边界

```text
粘贴文本 -> renderer 解析 -> 校验/合并 AppConfig.localValues -> config:save -> internal config.json
选择目录 -> renderer -> preload -> main dialog -> 返回绝对路径 -> config:save -> internal config.json
```

- 新增 IPC 仅返回结构化字符串结果，不暴露 Node API。
- 解析函数放在 shared 层，供 renderer 和 Node 测试共同使用。
- 目录选择不保证目录存在项目入口文件；现有服务运行时读取逻辑负责处理实际文件错误。

## 测试标准

- 缓存解析测试：空行、首个等号、重复键、内部空格和无效行。
- Renderer/API 合同测试：新增目录选择 IPC 通道和 preload 方法存在且名称一致。
- UI 合同测试：缓存输入、保存按钮和项目目录选择按钮使用中文文案。
- 完整 `npm test`、`git diff --check`、x64 DMG 构建和自动 DMG 验证通过。
