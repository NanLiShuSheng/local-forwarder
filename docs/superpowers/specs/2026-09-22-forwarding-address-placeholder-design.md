# 概览转发地址示例提示设计

## 目标

当“概览”中的 `/reqxml` 转发地址输入框为空时，根据地址类型显示对应的示例地址，帮助用户理解输入格式。

## 行为

- `hq` 输入框为空时显示 `60.12.9.58:7778`。
- `jy` 输入框为空时显示 `123.103.83.82:6064`。
- `zx` 输入框为空时显示 `123.103.83.82:6064`。
- 示例地址只作为 HTML input 的 `placeholder` 展示，不写入 `addressDrafts`、`tcpTargets` 或地址历史。
- 用户输入非空地址后，浏览器原生 placeholder 自动隐藏；现有失焦自动保存、顺序校验和历史地址行为保持不变。

## 实现范围

- 修改 `src/renderer/components/ConfigPages.tsx`：集中定义三类地址的 placeholder，并在地址输入框按索引使用。
- 修改 `test/renderer/address-config.test.ts`：增加三个精确断言，覆盖 hq、jy、zx 的提示值及其在地址输入框中的使用。
- 不修改配置模型、持久化逻辑、地址解析逻辑、样式或其他页面。

## 测试与验收

- 先运行新增/更新的地址配置测试，确认在缺少实现时因提示值不匹配而失败。
- 实现后运行地址配置测试，确认三个 placeholder 与现有地址行为测试全部通过。
- 运行项目构建与完整测试套件，确认 TypeScript、Vite 构建和其他 renderer/core 测试不受影响。
- 通过代码检查确认示例地址没有作为默认输入值参与保存。

## 非目标

- 不将示例地址预填为实际配置。
- 不改变已有配置或迁移用户历史地址。
- 不新增运行时网络请求或校验规则。
